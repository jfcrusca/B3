📖 Manual do Operador Sniper

1. O Score (0-100):

Priorize ativos com Score > 80. Eles possuem confluência de Médias, Fibonacci e Volume.

2. Ponto de Entrada:

O robô sugere a compra no nível Fibo 61.8%. Se o preço já estiver lá, o status será "Market". Se estiver acima, use uma ordem "Limit".

3. Gestão de Risco:

O Stop Loss é calculado abaixo do nível 78.6% de Fibonacci ou 1x ATR. Nunca mova o stop para baixo após entrar na operação.

4. Dashboard:

Sempre atualize o Dashboard após rodar o Scanner para ver a distribuição de setups do dia.
